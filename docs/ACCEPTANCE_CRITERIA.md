# Критерии приёмки этапов

Статусы функций: не начата · в разработке · реализована, не проверена · проверена
автоматически · проверена интеграционно · проверена в целевом окружении ·
заблокирована внешними условиями.

**Этап 2 — фундамент** (статусы на 2026-10-25)

| Критерий                                                                 | Статус                                                             |
| ------------------------------------------------------------------------ | ------------------------------------------------------------------ |
| `pnpm typecheck`, `pnpm lint`, `pnpm test` проходят; сборка web и server | проверена автоматически                                            |
| `docker compose config` валиден                                          | проверена автоматически                                            |
| `docker compose up` поднимает все сервисы                                | проверена в CI (GitHub Actions); на целевом сервере — не проверена |
| readiness = 200 при живых БД и Redis, 503 при недоступной БД             | проверена интеграционно                                            |
| Миграция на пустую БД; повторный запуск — без изменений                  | проверена интеграционно (PostgreSQL 16 локально, 17 — в CI)        |
| Задание BullMQ переживает перезапуск/падение worker                      | проверена интеграционно                                            |
| Без обязательных env приложение не стартует, ошибка на русском           | проверена (запуск собранного процесса)                             |
| В логах нет значений секретов                                            | проверена автоматически + на логах запущенных процессов            |

**Этап 3 — Telegram и авторизация** (статусы на 2026-10-25)

| Критерий                                                                                                             | Статус                                                         |
| -------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| Подделанный / просроченный / подписанный другим ботом initData → 401                                                 | проверена автоматически и интеграционно                        |
| Чужой пользователь Telegram → 403, событие в журнале                                                                 | проверена интеграционно                                        |
| Защищённые маршруты без сессии, с мусорным, истёкшим, отозванным токеном → 401                                       | проверена интеграционно                                        |
| В БД хранится только хэш токена сессии                                                                               | проверена интеграционно                                        |
| Ограничение частоты входа → 429                                                                                      | проверена интеграционно                                        |
| Webhook без секрета / с неверным секретом → 401; повторная доставка не дублирует задание                             | проверена интеграционно                                        |
| Подключение канала: все права / нехватка прав / владелец не админ / бот не админ / не канал / не найден / 429        | проверена интеграционно (имитация Bot API)                     |
| Чужой канал недоступен через прямой вызов API                                                                        | проверена интеграционно                                        |
| Бот добавлен владельцем → «обнаружен» + уведомление; добавлен чужим → игнор; удалён → `bot_removed` + предупреждение | проверена интеграционно (webhook → очередь → worker)           |
| Уведомление переживает 429 (`retry_after`)                                                                           | проверена интеграционно                                        |
| `/start`: владельцу — кнопка Mini App, постороннему — отказ                                                          | проверена интеграционно                                        |
| Работа с настоящим ботом, каналом и Telegram-клиентами (iOS, Android, Desktop)                                       | **не проверено** — нужны токен, домен и канал на вашем сервере |
| Удаление/закреп сообщений старше 48 ч                                                                                | этап 6                                                         |

**Этап 4 — публикации** (статусы на 2026-10-25)

| Критерий                                                                                         | Статус                                                              |
| ------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------- |
| Валидация лимитов Telegram до отправки (текст, подпись, альбом, размеры, кнопки, ссылки, UTF-16) | проверена автоматически (общий код браузера и сервера)              |
| Автосохранение с версиями; конфликт → выбор версии; восстановление несохранённого после закрытия | сервер — проверен интеграционно; интерфейс — не проверен в Telegram |
| Публикация сразу и по расписанию; перенос; отмена                                                | проверена интеграционно                                             |
| Многоканальная публикация — отдельный результат по каждому каналу                                | проверена интеграционно                                             |
| Отложенная публикация после перезапуска worker                                                   | проверена интеграционно                                             |
| Одновременный запуск одной отправки → один пост                                                  | проверена интеграционно                                             |
| 429 → повтор после retry_after, ровно одна отправка                                              | проверена интеграционно                                             |
| Обрыв после отправки → `ambiguous` без автоповтора; решение владельца                            | проверена интеграционно                                             |
| Отказ соединения → безопасный повтор                                                             | проверена интеграционно                                             |
| Реконсилятор: потерянное задание и зависшая отправка                                             | проверена интеграционно                                             |
| Альбом с загрузкой и повторной отправкой по file_id                                              | проверена интеграционно (имитация Bot API)                          |
| Загрузка медиа: тип по сигнатуре, лимиты, доступ только владельцу                                | проверена интеграционно                                             |
| Календарь, фильтры, часовой пояс установки                                                       | расчёты проверены автоматически; интерфейс — не проверен            |
| Реальная отправка в канал, вид поста в клиентах Telegram                                         | **не проверено** — на сервере                                       |

**Этап 5 — аналитика**

- Для каждой метрики в UI указан источник и период; «нет данных» ≠ 0.
- Расчёты (Δ, базовая линия, лучшее время) покрыты unit-тестами на фиксированных данных.

**Этап 6 — реклама**

- Статус оплаты и статус публикации независимы.
- Закреп/открепление/удаление переживают перезапуск и не дублируются.
- Публичный отчёт не содержит контактов, комментариев, цены (тест на ответ API);
  отозванный токен → 404.
- Трекинг: нельзя перенаправить на произвольный URL; боты-превью не считаются кликами.

**Этап 7 — AI**

- Ключ не попадает в ответы API и логи (тест).
- Обработаны 401/429/5xx/тайм-аут/невалидный JSON (тесты с моками).
- Аналитический ответ содержит раздел фактов, период и оценку достаточности данных.

**Этап 8 — готовность к продаже**

- Установка на чистый поддерживаемый Ubuntu LTS по документации — проверена.
- Бэкап → восстановление на отдельной среде — проверено.
- Обновление с предыдущей версии без потери данных — проверено.
- Таблица функций со статусами — актуальна.
