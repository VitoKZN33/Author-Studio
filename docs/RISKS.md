# Существенные технические и продуктовые риски

| #    | Риск                                                                                                                              | Влияние                                                                                        | Митигация                                                                                                                                  |
| ---- | --------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| R-1  | **Просмотры и пересылки недоступны через Bot API**                                                                                | «Аналитика» и рекламные отчёты без главной метрики Telegram                                    | честное «недоступно», ручной ввод, опциональный MTProto-коннектор по решению владельца                                                     |
| R-2  | **Регуляторный: ФАС относит Telegram к ресурсам с ограниченным доступом; ответственность за рекламу отложена до конца 2026**      | ценность рекламного кабинета для РФ с 2027 года не определена                                  | модуль рекламы не завязан на РФ-специфику; ОРД — отдельный адаптер; следить за позицией ФАС/РКН до этапа 6                                 |
| R-3  | Правило 48 часов у `deleteMessage`                                                                                                | автоудаление рекламы «1/72», «1/7 дней» может не сработать                                     | проверка на реальном канале на этапе 6; при ошибке — статус «требует ручного удаления» и уведомление                                       |
| R-4  | Нет идемпотентности `send*` в Bot API                                                                                             | дубли при сетевых сбоях                                                                        | статус `AMBIGUOUS` без автоповтора, блокировки, уникальные ключи                                                                           |
| R-5  | Атрибуция подписок невозможна в общем случае                                                                                      | неверные выводы о рекламе                                                                      | только наблюдаемые изменения с окном и базовой линией; клики ≠ подписки                                                                    |
| R-6  | `chat_member` в каналах может доставляться не всегда                                                                              | неполные данные вступлений                                                                     | считать дополнительным источником, основной — снимки числа подписчиков                                                                     |
| R-7  | Лимиты файлов Bot API (50 МБ загрузка)                                                                                            | крупные видео не опубликовать                                                                  | валидация до отправки; Local Bot API Server — как будущая опция                                                                            |
| R-8  | Слово «Telegram» в названии продукта                                                                                              | претензии к бренду (API Terms запрещают его в названии клиентских приложений без «Unofficial») | название по умолчанию без «Telegram», конфигурируемое                                                                                      |
| R-9  | Доступность AI-провайдеров с VPS в РФ и оплата                                                                                    | AI-модуль не работает у части покупателей                                                      | OpenAI-compatible с произвольным base URL, тест подключения, документация                                                                  |
| R-10 | WebView-различия (iOS/Android/Desktop/Web): клавиатура, cookies, safe area                                                        | сбои редактора и входа                                                                         | без cookies; тест-матрица клиентов на этапах 3–4; черновики на сервере                                                                     |
| R-11 | Изменения Bot API (выходят ~ежемесячно)                                                                                           | ломающие изменения                                                                             | клиентская библиотека с типами, слой-адаптер Telegram, проверка changelog перед релизом                                                    |
| R-12 | Резервные копии на том же VPS                                                                                                     | потеря сервера = потеря данных                                                                 | документировать внешнее хранилище (S3-совместимое/rsync), скрипт поддерживает выгрузку                                                     |
| R-13 | Инфраструктура рабочей среды (доступ к npm, GitHub)                                                                               | сборка невозможна                                                                              | решено 2026-10-25: репозиторий подключён, реестр доступен                                                                                  |
| R-14 | Docker-образы не собираются в рабочей среде разработки (Docker Hub закрыт)                                                        | ошибки сборки видны только в CI                                                                | закрыт: CI собирает образы и запускает compose на каждый push                                                                              |
| R-15 | Скрипт telegram-web-app.js загружается с telegram.org; при ограничениях доступа из сети пользователя Mini App не получит initData | вход невозможен                                                                                | проверить на устройствах в РФ на этапе 3; запасной вариант — раздавать копию скрипта со своего домена с регулярным обновлением             |
| R-16 | Уведомления не доставляются, пока владелец не нажал «Старт» в боте (Telegram запрещает боту писать первым)                        | владелец не узнает о проблемах с каналом                                                       | в инструкции первым шагом — открыть бота и нажать «Старт»; ошибка 403 фиксируется в логе                                                   |
| R-17 | **Подтверждено на сервере:** из дата-центров РФ api.telegram.org может быть недоступен                                            | бот не работает без прокси                                                                     | `TELEGRAM_PROXY_URL` + режим polling (ADR-024); в документации покупателю — требование прокси или сервера вне РФ                           |
| R-18 | AI-провайдер недоступен из страны сервера или меняет названия моделей                                                             | AI не работает                                                                                 | проверка подключения в настройках, прокси, свободное поле модели; ошибки провайдера показываются как есть                                  |
| R-19 | Модель может выдумать факты или числа                                                                                             | неверные выводы владельца                                                                      | факты считает приложение; неподтверждённые числа помечаются; AI только предлагает                                                          |
| R-20 | Сеанс аккаунта владельца (MTProto) на сервере даёт полный доступ к аккаунту                                                       | компрометация сервера = доступ к аккаунту                                                      | шифрование, только чтение просмотров, отключение одной кнопкой, видно в «Устройствах» Telegram; в документации покупателю — предупреждение |
| R-21 | Telegram может ограничить аккаунт за запросы API                                                                                  | пауза сбора просмотров                                                                         | один запрос на 100 постов раз в час, FLOOD_WAIT → пауза                                                                                    |
